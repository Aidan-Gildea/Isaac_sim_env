# CLAUDE.md

## Research policy

Look up anything that is not directly common sense using the WebSearch tooling.

- "Common sense" means universally obvious facts that need no verification (e.g. the sky is blue, water is wet).
- Everything else — API signatures, version-specific behavior, library/tool details, Isaac Sim specifics, error messages, best practices, current facts, anything you are not certain of — must be verified with WebSearch before answering or acting on it.
- Do not rely on memory or guess when a lookup is possible. When in doubt, search.
